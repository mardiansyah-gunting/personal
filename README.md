# Portfolio Web

Mardiansyah Gunting's one-page portfolio, live at <https://mardiansyah-gunting.github.io/personal/> in English, Indonesian (`/id/`) and Chinese (`/zh/`).

The design follows the "folio" template: one quiet column, hand-drawn underlines, card rails that grow into detail sheets, a 3D "dive" photo gallery, and a footer that turns the page dark. Every piece of text is set in handwriting: **Kalam** for Latin, **LXGW WenKai Screen** for Chinese, **Mrs Saint Delafield** for the signature. Contact is email-only — the Available badge and footer email copy the address to the clipboard; there is no phone number.

## Stack

- [Next.js](https://nextjs.org) 16 (App Router) exported as a static site, React 19, Tailwind CSS 4
- Vitest for content and helper tests, Playwright for end-to-end tests against the built site
- GitHub Pages, deployed by `.github/workflows/deploy.yml` on push to `main`

## Commands

```bash
npm install
npm run dev        # http://localhost:3000/personal/
npm test           # unit tests (content, helpers)
npm run build      # static export to out/
npm run test:e2e   # serves out/ at http://localhost:4321/personal/ and runs Playwright
npm run photos     # regenerate web-sized job photos + content/photos.json
```

`npm run test:e2e` needs a fresh `npm run build` first. The contact form is never really submitted in tests (the request is intercepted).

## Where things live

```
content/
  types.ts        the Site shape every language fills in
  shared.ts       language-free data: organisation links, logos, project tags and links, CV links, contact
  en.ts id.ts zh.ts   one Site object per language (localised copy; tags and skill items stay in shared.ts)
  photos.json     generated by `npm run photos`
app/
  (en)/           English root layout + page at /
  (intl)/[lang]/  Indonesian and Chinese pages at /id/ and /zh/
  globals.css     design tokens and component CSS (fonts, tiles, rails, sheets, gallery, board)
components/       Hero, Intro (Now + Organizations), Projects, Skills, Experience, Education,
                  DiveGallery, Footer, SheetProvider (project / experience / contact sheets)
lib/              asset() base-path helper, language routes, metadata, sheet deep links, rich-text tokenizer
public/images/    logos, schools, job photos (originals in jobs/, web copies in jobs-web/)
tests/            unit tests; tests/fixtures/i18n/ holds the previous site's text as the source of truth
e2e/              Playwright specs
```

### Editing content

- Change wording in `content/en.ts`, `content/id.ts` and `content/zh.ts`. `npm test` checks that the three languages keep the same structure and that job titles, periods, descriptions and education stay identical to `tests/fixtures/i18n/`.
- Organisation websites, project links and the CV links are in `content/shared.ts`.
- New job photos: add them to `public/images/jobs/<role-slug>/`, run `npm run photos`, commit the generated files.

### Deep links

`#/work/<project>`, `#/experience/<role>` and `#/contact` open the matching sheet, in any language.

## Remotes

`origin` is the master-data repository (branches `dev` and `main`). `personal` is the publication repository served by GitHub Pages under `/personal`.
